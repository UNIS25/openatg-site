# Varathans25 commerce source

See [backend, setup and deployment instructions](../docs/VARATHANS25_ADMIN_BACKEND.md) and [verification results](../docs/VARATHANS25_COMMERCE_VERIFICATION.md).

This directory contains the secure static admin frontend, reusable storefront integration, local-only test harness and tests. It is not itself a publishable static export. Build output is in `dist/adminpage/`.

The approved storefront is not modified by this worktree. Integration/publication awaits the missing original product commits.
