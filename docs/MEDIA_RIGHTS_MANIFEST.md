## Release and upload boundary

`v25-editorial-private` is a private, size/MIME-restricted quarantine bucket with no browser upload grant. `v25_media_assets` has admin-only RLS, approval evidence fields and audit triggers. Unapproved media is not exposed by the public configuration endpoint. A future upload worker must authenticate the named administrator, enforce CSRF/rate limits, validate real container/codec/dimensions/duration, strip metadata and all audio, scan/transcode in isolation, and write an immutable approval reference before allowing publication. File extensions or client-supplied MIME alone must never authorize publication.

No working upload/publish control is implied in this release: upload processing and the commercial media approval workflow remain deliberately unconnected. Admins can manage the supplied study versus poster-only mode, chapter order, DE/FR/EN copy and invitation scheduling now. A later reviewed integration may replace the fixed allowlist with validated, approved media IDs.

Screenshots in the cinematic review gallery are original renders of this staging application. They inherit the underlying image-rights restrictions above. No credentials or member-pass tokens are included.
