ATG Base 64M v1

Building the stack,
not just an application.

An independently trained 64.3-million-parameter trilingual ATG base model, built from random initialization using ATG's own decoder architecture and trilingual tokenizer. Base 64M completed 600 million tokens of English, Sinhala and Tamil pretraining and represents the next major milestone in OpenATG's compact-model research programme.

Technical Notes

Why Base 64M matters

OpenATG is building the model stack, not simply fine-tuning an existing international foundation model.

ATG Base 64M began from random initialization and uses an ATG-authored decoder architecture together with an independently trained English-Sinhala-Tamil tokenizer.

The milestone demonstrates the complete path from corpus preparation and tokenization through model initialization, GPU training, checkpointing and post-training evaluation.

Base 64M is a research base model rather than a finished assistant. Generation quality, factual reliability and repetition remain active research areas.

Model artifact

Distribution review in progress

The trained Base 64M checkpoint is preserved and cryptographically verified. A privacy-safe inference package is being prepared subject to provenance, licensing and distribution clearance.

No Base 64M model artifact is available for public download at this stage.
